# Rocket-Game 
# Rocket Run – Mini-Game dezvoltat în Godot

# Rocket Run este un joc 3D arcade în care jucătorul controlează o mică rachetă și trebuie să navigheze printre obstacole pentru a ajunge la platforma de aterizare. Proiectul a fost realizat folosind Godot Engine 4.5 și reprezintă o combinație de elemente simple de fizică, design UI și mecanici de gameplay de bază.

# Descrierea jocului

# Jucătorul controlează racheta prin:

# A / D – control lateral

# Space – activarea motorului principal (thrust)

# Obiectivul fiecărui nivel este de a evita obstacolele, de a gestiona impulsul rachetei și de a ateriza în siguranță pe platforma finală.
